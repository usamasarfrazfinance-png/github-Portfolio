Case Study 03 · Non-Profit

Paritta Group (Children International)

Process automation and application lifecycle management for a Dynamics 365 CRM deployment supporting an international children's welfare organisation.

Role: Dynamics CRM Consultant Environment: D365 CE
C# PluginsAzure FunctionsAzure Webhooks Unit TestingUI Automation (C#)Azure DevOps

Overview

Paritta Group runs core CRM processes on Dynamics 365 for Children International's programme and donor operations. My work focused on automating recurring processes with plugins and Azure Functions, and on getting proper test coverage in place around that logic.

Process automation

I built C# plugins and Azure Webhook integrations to automate core CRM processes that had previously relied on manual steps, reducing the amount of repetitive work needed to keep records and workflows current.

Testing and quality

I set up unit tests around the plugin logic and built C#-based UI automation tests to catch regressions before they reached production, which mattered given how tightly the automated processes were tied into day-to-day operations.

Lifecycle management

Code and task management ran through Azure DevOps end to end, giving the team a consistent pipeline for tracking changes and deploying updates to the CRM environment.
